Kavita-NG

Angular components, services, pipes and theme tokens shared by Kavita and related projects.

Getting started

Load Bootstrap first, then the library styles. The font partial is optional.

{{ stylesUsage }}

A theme sets --kng-* variables on body or below. Browse and edit them on the Tokens page, then pick any section in the side nav to see them applied. The theme picker in the header switches between sample themes.
